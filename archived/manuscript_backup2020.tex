\begin{abstract}
Solar-physics analysis increasingly depends on observations from multiple instruments and on software distributed across languages, packages, and data services. Finding the right observation, identifying the correct data product, and translating scientific intent into reliable analysis code can therefore consume substantial effort before physical interpretation begins. We present StiXpert, a domain-specific AI-assisted system for discovery and analysis of data from the Spectrometer/Telescope for Imaging X-rays (STIX) on Solar Orbiter. The system connects a general-purpose AI client to a curated, searchable knowledge base covering STIX instrument and data-product knowledge, Python and IDL software, examples, and public data-centre interfaces. Through a tool-mediated interaction model, the assistant can retrieve source-grounded information, explain analysis workflows, and draft client-side code while retaining provenance to indexed symbols, documentation, and source files. A worked flare-analysis workflow is described for observation discovery, light-curve generation, spectral analysis, and image reconstruction in Python and SolarSoft/IDL. The present paper specifies a verification protocol for knowledge discovery, cross-language code assistance, and scientific reasoning; quantitative and event-specific outcomes are intentionally left as fields for completion after controlled experiments. StiXpert is designed to reduce the programming and software-navigation overhead of solar research, not to replace instrument expertise, validation, or scientific judgement.
\end{abstract}
